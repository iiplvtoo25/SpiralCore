# Spiral Core – Team Task Manager

**Course:** IMS566 Advanced Web Design Development and Content Management
**Name:** Iman Azlan | **Student ID:** 2026128589

## Description
Spiral Core is a small web application prototype for managing company tasks. It has a login page, a dashboard with charts, and two data pages (Tasks and Team).

## Features
- Login page with error feedback (hardcoded credentials)
- Responsive navigation bar shared by all pages, with logout
- Dashboard: summary cards, 5 charts (status, workload, priority, weekly deadlines, progress per member), upcoming deadlines
- Tasks page: table with live search and status filter
- Team page: member cards with workload count
- Footer and SEO metadata (title, description, keywords) on every page
